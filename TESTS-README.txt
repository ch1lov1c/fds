ПРОВЕРКА САЙТА

Для просмотра сайта Node.js и Playwright не нужны. Они требуются только для автоматической проверки.

1. Запустите локальный сервер в папке сайта: python3 -m http.server 8080
2. Установите Playwright в отдельной рабочей папке, не внутрь папки сайта, и установите Chromium для Playwright.
3. Запустите: SITE_URL=http://127.0.0.1:8080 node release-check.js

Проверка охватывает первый экран на разных размерах, отсутствие корзины и удалённых категорий, навигацию, вращение 3D-фигуры, четыре документа, 35 ссылок к форме и отключение без ID. Отправка формы проверяется через имитацию API: согласие, ошибка, сохранение введённого текста и повтор с тем же идентификатором. В том числе проверяется автономный просмотр index.html в изолированном iframe Workspace без сети. Реальную доставку в Telegram этот тест не подтверждает: её нужно отдельно проверить на опубликованном HTTPS-домене после настройки Zapnoty.

После изменений styles.css, fonts.css, bootstrap.js, main.js, core3d.js, шрифтов или изображений команды выполните python3 build-workspace-preview.py, чтобы обновить встроенную резервную версию index.html. Повторный запуск сборщика не изменяет файл, если источники не изменились.

Не публикуйте release-check.js, build-workspace-preview.py и этот текст в веб-корне.
